## آدرس‌ها

| چیز | آدرس |
|---|---|
| Bot API | `https://tapi.bale.ai/bot<TOKEN>/<METHOD>` |
| دانلود فایل | `https://tapi.bale.ai/file/bot<TOKEN>/<file_path>` (حدود ۱ ساعت معتبر) |
| Business API | `https://tapi.bale.ai/business/bot<TOKEN>/<METHOD>` |
| لینک ربات | `https://ble.ir/<username>?start=<param>` |

نام متدها حساس به حروف نیست؛ هم GET و هم POST پشتیبانی می‌شود. پارامترها به صورت JSON، فرم یا query؛ آپلود فقط multipart.

## تفاوت با تلگرام

بله «شبیه» Bot API تلگرام است ولی **همان نیست**:

| موضوع | بله |
|---|---|
| `parse_mode` | ندارد؛ همه‌ی متن‌ها Markdown بله هستند (`**پررنگ**`، `__کج__`) |
| `allowed_updates` | ندارد |
| secret token وب‌هوک | ندارد (مسیر را مخفی بگیرید) |
| انواع آپدیت | فقط `message`، `edited_message`، `callback_query`، `pre_checkout_query` |
| نظرسنجی، inline mode، بازی | ندارد |
| پرداخت | فقط کیف پول بله (ریال)؛ کارت‌به‌کارت حذف شده |
| `askReview`، `inquireTransaction`، `createInvoiceLink` | مخصوص بله |
| دکمه‌ی رنگی (`style`) | مخصوص بله (بتا) |
| Business API | مخصوص بله |

## رفتارهای مهم

### کلاینت‌های قدیمی و `answerCallbackQuery`
این متد از خرداد ۱۴۰۴ به کلاینت‌های بله اضافه شد. اگر شناسه‌ی callback با **`1`** شروع شود، کلاینت قدیمی است و پاسخ‌دادن پشتیبانی نمی‌شود. `query.answer()` در baleropy این را خودکار رد می‌کند.

### 🧪 `chat_id` را رشته بفرستید
در آزمایش واقعی، `sendChatAction` با `chat_id` **عددی** در JSON خطای `400 chat id is empty` داد ولی با رشته کار کرد. baleropy از نسخه‌ی ۰.۲ همیشه `chat_id` را رشته می‌فرستد؛ اگر خودتان درخواست خام می‌زنید همین را رعایت کنید.

### 🧪 متدهای گروه روی چت خصوصی
`getChatMember`، `getChatAdministrators` و `getChatMembersCount` روی چت خصوصی `400 unsupported peer type` می‌دهند. `getChat` روی چت خصوصی کار می‌کند.

### 🧪 `403 permission_denied`
وقتی ربات اجازه‌ی نوشتن ندارد: کاربر بلاکش کرده، هنوز `/start` نزده، یا در گروه محدود است. برای ارسال انبوه این خطا را بگیرید و کاربر را از لیست حذف کنید.

### 🧪 ۴۲۹ و `retry_after`
پاسخ ۴۲۹ فیلد `parameters.retry_after` (ثانیه) دارد. baleropy صبر و تلاش مجدد را خودکار انجام می‌دهد.

### ناسازگاری‌های خود مستندات
- فیلد `reply_markup` در `Message` به‌اشتباه `InlineKeyboardButton` نوشته شده؛ baleropy هر دو شکل را می‌پذیرد.
- `sendPhoto` در مستندات پارامتر `from_chat_id` دارد که ظاهراً از `forwardMessage` کپی شده؛ استفاده نمی‌شود.
- `InputSticker` ارجاع داده شده ولی تعریف نشده است؛ شکل `sticker` + `emoji_list` در baleropy حدسی است.
- نام‌های `Transaction` (`userID`، `createdAt`) camelCase هستند.

## توصیه‌های عملی

::: tip خلاصه‌ی بهترین رویه‌ها
1. `skip_updates=True` در polling.
2. متن بلند را با `split_text` تکه کنید.
3. همیشه به callback پاسخ بدهید.
4. برای اعلان انبوه از Business API استفاده کنید.
5. دکمه‌ی رنگی را فقط «کمک بصری» بدانید.
:::
