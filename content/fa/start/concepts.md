## async در یک دقیقه

baleropy **ناهمگام (async)** است. یعنی وقتی ربات منتظر جواب شبکه است (مثلاً ارسال پیام)، پایتون می‌تواند کار دیگری انجام دهد و ربات هم‌زمان به هزاران کاربر خدمت کند. شما فقط دو قانون را رعایت می‌کنید:

1. توابعی که با شبکه کار می‌کنند `async def` هستند.
2. هر جا نتیجه‌ی یک کار async را می‌خواهید، قبلش `await` می‌گذارید.

```python
async def handler(message):
    await message.answer("سلام")      # درست: await
    # message.answer("سلام")          # غلط: بدون await هیچ پیامی ارسال نمی‌شود!
```

::: warn کار سنگین و blocking نکنید
کدهایی مثل `time.sleep(5)` یا `requests.get(...)` کل ربات را متوقف می‌کنند. به‌جایشان از `await asyncio.sleep(5)` و کتابخانه‌های async (مثل `aiohttp`) استفاده کنید.
:::

## اجزای اصلی

| بازیگر | نقش |
|---|---|
| **Bot** | ارتباط با سرور بله: همه‌ی متدها (`send_message` و ...) روی آن هستند. |
| **Dispatcher** | ریشه‌ی درخت روترها. آپدیت می‌گیرد، اجرای ربات را (polling/webhook) مدیریت می‌کند. |
| **Router** | گروهی از هندلرها. می‌تواند روترهای دیگر را داخل خودش بگیرد. |
| **Handler** | تابع شما که به یک رویداد پاسخ می‌دهد. |
| **Filter** | شرط اجرای هندلر (متن چیست؟ دستور است؟ در کدام حالت هستیم؟). |
| **Middleware** | کدی که دور هندلر می‌پیچد (لاگ، آمار، دیتابیس، محدودیت نرخ). |
| **FSM** | حافظه‌ی گفتگو: کاربر الان در کدام مرحله است؟ |

## انواع رویدادها

هر رویداد یک «ناظر» (observer) روی Router دارد که با دکوراتور از آن استفاده می‌کنید:

| ناظر | چه زمانی؟ | ورودی هندلر |
|---|---|---|
| `router.message` | پیام جدید | `Message` |
| `router.edited_message` | ویرایش پیام | `Message` |
| `router.callback_query` | زدن دکمه‌ی inline | `CallbackQuery` |
| `router.pre_checkout_query` | تایید نهایی پرداخت | `PreCheckoutQuery` |
| `router.error` | خطا در یک هندلر | `ErrorEvent` |

::: tip شروع و پایان ربات
`@dp.on_startup` و `@dp.on_shutdown` تابعی را موقع روشن و خاموش‌شدن ربات اجرا می‌کنند؛ مناسب برای اتصال به دیتابیس.
:::

## «اولین هندلرِ مطابق، برنده است»

برای هر رویداد، baleropy هندلرها را به ترتیب ثبت بررسی می‌کند. اولین هندلری که **همه‌ی فیلترهایش** درست باشد اجرا می‌شود و بقیه نادیده گرفته می‌شوند. نمونه‌ی تعاملی زیر را امتحان کنید؛ امکان تغییر نوع پیام هم وجود دارد:

::: note اگر هیچ هندلری نخورد؟

:::

## ساختار پیشنهادی پروژه

```text
my_bot/
├── bot.py              # ساخت Bot و Dispatcher و اجرا
├── config.py           # توکن و تنظیمات
├── middlewares.py      # میدلورهای شما
├── filters.py          # فیلترهای کاستوم
├── states.py           # StatesGroup ها
└── handlers/
    ├── __init__.py
    ├── start.py        # router = Router(); /start و منو
    ├── shop.py         # router = Router(); فروشگاه
    └── admin.py        # router = Router(); دستورهای مدیریتی
```

```python title="bot.py"
from handlers import start, shop, admin

dp = Dispatcher()
dp.include_routers(start.router, shop.router, admin.router)
```
